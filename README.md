# task_manager

複数人向けのタスク管理アプリ。

## 概要

タスクの登録・一覧表示・状態管理を行うWebアプリケーション。
GitHubのIssue番号を記録でき、開発タスクと紐付けて管理できる。

## 技術スタック

| 層 | 技術 |
|---|---|
| フロントエンド | React + Vite |
| バックエンド | Node.js + Express |
| データベース | PostgreSQL |
| 実行環境 | ローカル（v0.1時点） |
