# 要件定義書

## 1. 概要

複数人で利用するタスク管理アプリ。
タスクの登録・一覧・状態管理を行い、GitHubのIssue番号を記録できる。

## 2. 利用者

- ユーザー数：複数人
- ログイン機能：必要

## 3. エンティティ

### タスク（tasks）

| 項目 | 型 | 必須 | 説明 |
|---|---|---|---|
| id | 整数 | ○ | 主キー |
| title | 文字列 | ○ | タスク名 |
| description | テキスト | | 詳細 |
| status | 文字列 | ○ | 状態（未着手/進行中/完了） |
| due_date | 日付 | | 期限 |
| issue_number | 文字列 | | GitHubのIssue番号 |
| assignee_id | 整数 | | 担当者ID（usersへの参照） |
| created_at | 日時 | ○ | 作成日時 |
| updated_at | 日時 | ○ | 更新日時 |

### ユーザー（users）

| 項目 | 型 | 必須 | 説明 |
|---|---|---|---|
| id | 整数 | ○ | 主キー |
| name | 文字列 | ○ | 表示名 |
| email | 文字列 | ○ | ログインID |
| password_hash | 文字列 | ○ | パスワード（ハッシュ化） |
| created_at | 日時 | ○ | 作成日時 |

## 4. 機能一覧（v0.1）

| ID | 機能 |
|---|---|
| F-01 | ユーザー登録ができる |
| F-02 | ログイン・ログアウトができる |
| F-03 | タスクを作成できる |
| F-04 | タスク一覧を表示できる |
| F-05 | タスクを編集できる |
| F-06 | タスクの状態を変更できる |
| F-07 | タスクを削除できる |
